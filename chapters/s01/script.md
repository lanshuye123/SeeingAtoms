## 1. 旁白正文

### 00:00–01:05 样品槽里的白粉

一小堆白色粉末，装在样品槽里，表面被刮得很平。看上去像面粉。

它可能是药片里的有效成分，也可能是陶瓷、催化剂，或者电池材料。

衍射仪不神秘：X 射线管、样品台、探测器。

可就在这堆粉末里，每一颗小晶粒的原子，都按同一套规矩重复排列。

我们想知道这套规矩是什么。

晶相、晶胞、晶粒大小，都会影响材料怎么用。

可见光帮不上忙。它的波长大约半微米，原子间距只有零点几纳米，差了三五千倍。

问题不在放大倍数，在尺子太粗。

显微镜的分辨率，受探测波长的限制。波长太长，两个靠得很近的原子，在图像里就糊成一个点。

### 01:05–01:47 换一把尺子

换一把尺子。实验室里最常见的 X 射线，波长 1.54 埃，约零点一五纳米，差不多就是原子间距。

一埃是零点一纳米。

它照到粉末上，原子周围的电子被推得上下抖动，向各个方向发出次波。

这些次波会打架。方向不对，互相抵消；方向对了，叠成一条很亮的线。

物理上，这叫衍射。

屏幕上不会出现原子的影子。出现的是一幅由加强和抵消写成的图样。

### 01:47–03:09 布拉格：别被“反射”骗了

一九一三年，布拉格父子把这件事讲清楚了。

他们的办法很省事：把一层层原子面画成一面面镜子。

一束 X 射线斜着照进来，打到相邻两层。相邻两层的光程差，是两倍的晶面间距，乘以角度的正弦。

这段路如果正好是波长的整数倍，两层的波就对齐了。

写成式子：二倍的晶面间距，乘以角度的正弦，等于波长的整数倍。这里的晶面间距，是相邻两层原子面的距离；角度，是射线和晶面的夹角。

这个式子把角度和间距锁在一起：间距越大，峰越靠前。

别被“反射”两个字骗了。原子面不是镜子。镜子只把一个方向的波弹回来。它们往四面八方都发次波，只不过在满足布拉格条件的方向上，大家才正好同相。

单层原子面的散射很弱。可晶体里有大量平行的原子面；它们一起同相叠加，峰才亮得起来。

### 03:09–04:19 粉末：用数量换角度

单晶衍射很挑角度。你得把晶体转来转去，某个角度才亮一下。

粉末样品省事得多。成千上万颗小晶粒，朝向乱七八糟。你转一颗晶体要试的所有角度，它们一次性替你试完了。

对每一组晶面，总有一些晶粒正好站在对的角度。它们发出的光，在空间里围成一个圆锥。

探测器扫过去，碰到一个圆锥，记一个峰。

一条衍射曲线，就这么来的。横坐标是衍射角，纵坐标是强度。

每种晶体都有自己的峰位组合，像一套指纹。物相鉴定靠的就是这个。

X 射线晶体学不提供一张原子照片。它记录一张衍射图，再用数学和模型，把图里的信息反推回原子排列。

### 04:19–04:56 峰位：先看峰在哪

拿到一条曲线，先看峰在哪。

峰位最老实。每一个峰位对应一个晶面间距；几个峰联立，就能定晶胞的形状和大小。

晶胞是晶体的基本重复单元。它的尺寸和形状，限制了原子能站多近，也影响它们怎么成键。

当然，样品高度、仪器零点，也会让峰整体挪一点。做精修之前，得先把这些账算清楚。

### 04:56–05:36 峰高：没那么老实

峰高就没那么老实了。

原子种类不同，散射本领不同；原子站的位置不同，次波的相位不同。

把晶胞里所有原子的贡献加起来，就是结构因子。某些方向上，次波正好抵消，峰就没了。

同一物相，制样方式不同，峰高也会变。片状晶粒喜欢平躺，这叫择优取向。

峰高能读出原子信息，但它不是一张可以直接换算的表格。

### 05:36–06:26 峰宽：与晶粒有关，但不只与晶粒有关

峰宽和晶粒大小有关。

晶体不是无限大。晶粒越小，衍射空间里的点越胖，峰越宽。谢乐公式说的就是这件事。

不过，峰宽不是只有这一个来源。仪器有展宽，晶格有应变，缺陷也会插一脚。

所以，想拿峰宽算尺寸，先测一个标准样品，把仪器的账扣掉。再看单个峰给出的，往往是沿某个晶面法向的厚度，不是一颗颗粒的直径。

衍射给出的尺寸，和电镜里量到的颗粒直径，常常不是一回事。

### 06:26–07:56 两张图：硅与金红石

这三个量放在一起，能做什么？拿两个晶体试试。

单晶硅，金刚石立方结构，晶胞里有八个硅原子。金红石，四方结构，晶胞里有两个钛、四个氧。

用开放晶体结构数据库里的数据，按铜靶 X 射线算出来的谱线，是这样。

硅的峰很疏：二十八点四度、四十七点三度、五十六点一度。金红石的峰密得多，最前面的几根在二十七点四度、三十六点一度、四十一点二度。

峰位组合不一样，峰高比例也不一样。把两张图放在一起，没人会把硅认成金红石。

这就是物相鉴定：先对峰位，再对峰高；混合物就是把几套指纹叠在一起。

这是计算谱，不是实测。没有仪器展宽，也没有择优取向；真实的峰会宽一些，强度也会变。

### 07:56–08:56 边界：它喜欢整齐的东西

可这张图也有它的边界。X 射线衍射喜欢整齐的东西。

晶体太小、太乱，峰就塌成一团鼓包。

如果晶粒只有几纳米，峰宽得几乎连成一片。

它看到的是束斑里的平均。几种物相混在一起，少量缺陷、界面、纳米析出物，信号可能被基体淹掉。

如果样品里只有百分之几的杂相，它的峰可能小到看不出来。

它也偏心。轻元素电子少，散射弱；氢更是几乎看不见。

它也有省事的一面：通常，粉末压进槽里就能测，不用切开，也不用抽真空。

可它很会回答“平均来说，原子怎么排”；它没法告诉你“这个缺陷在哪颗晶粒里”。

### 08:56–09:24 桥接：换一种眼睛

要看局部，得换一种眼睛。

电子束的波长更短，跟物质作用更狠。它能衍射，也能被磁透镜重新聚成像。

电子显微镜能补上这一块，但它也有自己的代价：样品得薄，电子束还可能把样品本身改掉。

这是下一期的事。

### 09:24–10:30 片尾

（无旁白，黑色背景，向上滚动字幕。）

## 2. 这次改了什么（反 AI 味）

### 2.1 删掉的“AI 句式”

- 删掉“第一、第二、第三”的清单式推进，改成“先看峰在哪 / 峰高就没那么老实 / 峰宽更麻烦”的口语转折。
- 删掉每段末尾的“所以，这告诉我们……”式总结，让画面和下一句自己接上。
- 删掉“不是……而是……”的对称句，改成“问题不在……在……”等更松散的汉语表达。
- 删掉“首先/其次/最后”“值得注意的是”“不难发现”等路标词。
- 删掉空泛的“极其重要”“深远影响”，改用“晶相、晶胞、晶粒大小，都会影响材料怎么用”这种可验证的具体说法。
- 删掉“让我们……”式的主持人腔，改用“你”“我们”交替，但不过度亲切。

### 2.2 加回来的“人味”

- 具体场景：样品槽、刮平的粉末、X 射线管、样品台、探测器。
- 具体材料：药片、陶瓷、催化剂、电池材料；只说“可能”，不指向某一种样品。
- 有限度的拟人：峰位“老实”、峰高“没那么老实”、峰宽“更麻烦”、X 射线“有脾气”。
- 短句和停顿：一句只做一件事；公式前后留白。
- 允许“毛边”：不是每句话都解释干净，部分理解交给画面。
- 保留科学限定：“通常”“往往”“可能”“百分之几”，不把经验说法说成定律。

### 2.3 峰宽段的新写法（按 5.3 反馈）

- 先说“峰宽和晶粒大小有关”，并用谢乐公式建立关系。
- 再补“仪器展宽、晶格应变、缺陷”等其他来源。
- 最后才说单峰给的是法向厚度、不是颗粒直径。
- 没有用“别急着算粒径”这种提前否定的句子。

### 2.4 仍然保留的结构

- 冷开场 → 换尺子 → 布拉格 → 粉末 → 峰位/峰高/峰宽 → 边界 → 桥接。
- 这个顺序是科学理解的需要，不为了“反 AI”而打乱。
- 旁白不念符号；公式由画面承担。

## 3. 科学事实核对

详细逐条核对见 `chapters/s01/fact_check.md`。本稿涉及的核心事实：

1. 可见光波长约 400–700 nm；原子间距约 0.1–0.3 nm。见 F01/F02。
2. Cu Kα X 射线波长约 1.5406 Å，即约 0.15 nm。见 F03。
3. X 射线主要与电子云作用，散射波发生干涉。见 F04。
4. 布拉格条件为 2d sinθ = nλ；θ 是射线与晶面的夹角。见 F05/F06。
5. 布拉格公式中的“反射”是几何模型，不是镜面反射。见 F07。
6. 粉末中随机取向晶粒把同一晶面间距的衍射转成圆锥；探测器扫描得到强度—角度曲线。见 F08。
7. 峰位、峰强、峰宽分别关联晶格参数、原子排列、晶体完整性/尺寸。见 F09–F14。
8. 峰宽不只由晶粒尺寸决定；谢乐公式给出的是需要谨慎解释的相干尺寸。见 F12–F14。
9. X 射线衍射需要长程有序；无序样品出现弥散散射。见 F15。
10. X 射线束斑内是平均结果；轻元素/氢更难看清。见 F16/F17。
11. 常规 X 射线晶体学不直接给出原子级实空间图像，而是从衍射反演结构。见 F18。
12. 电子束与磁透镜可以实空间成像；电子波长更短，但样品需薄、可能损伤。见 F19–F21。
13. 常规粉末 XRD 通常不需要切开样品或抽真空；这是相对电子显微制样的便利之处。见 F23 / C35。

## 4. 术语表

| 术语 | 本片中的解释 | 备注 |
|---|---|---|
| 晶体 | 原子在三维空间中长程周期性排列的固体 | 不展开点阵/空间群 |
| 晶粒 | 一块内部取向一致的晶体小区域 | 颗粒可能由多个晶粒组成 |
| 晶面 | 晶体中原子排列相同、彼此平行的一组平面 | 用“原子面”做直观说法 |
| 晶面间距 d | 相邻两层平行原子面之间的距离 | 不要求观众会算 |
| 衍射角 2θ | 入射束与衍射束之间的夹角 | 画面用 2θ，旁白说“衍射角” |
| 布拉格条件 | 相邻晶面散射波光程差为波长整数倍时相长干涉 | 公式在画面上 |
| 粉末衍射 | 大量随机取向小晶粒的衍射叠加 | 不是“粉末的显微镜照片” |
| 晶胞 | 能重复拼出整块晶体的最小平行六面体单元 | 不展开 14 种布拉维格子 |
| 晶格参数 | 描述晶胞形状和大小的长度/角度 | 本片只提概念 |
| 结构因子 | 晶胞内所有原子散射波叠加后的总振幅 | 不要求计算 |
| 谢乐公式 | 峰宽与晶粒尺寸的关系 | 强调有前提、需扣仪器展宽 |
| 倒易空间 | 与实空间互为倒数关系的数学空间 | 本片用“衍射空间里的点”做直觉，不展开 |
| 长程有序 | 原子排列在很大范围内保持周期性 | 与“短程有序”相对 |
| 弥散散射 | 无序样品在较大角度范围内形成的宽鼓包 | 非晶/纳米晶常见 |

## 6. 旁白录制提示

- 语速：每秒约 4 个字，句间停顿 0.3–0.6 秒；公式句放慢。
- 重音：数字、转折（“可”“但”“别被”）、三个“峰”的段落。
- 语气：像在实验室里对一位聪明但没有专业背景的朋友解释，不是课堂点名，也不是广告。
- 不要念出画面上的符号；旁白已经把公式转成中文。
- 段落之间留白，便于后期按镜头切分。
- “它也有脾气”“峰位最老实”这类句子可以带一点笑意，但不要演成段子。
