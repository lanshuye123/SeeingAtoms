## 2. 需要特别留意的表述

### 2.1 “X 射线晶体学不提供一张原子照片”

这是本片的核心纠偏。严格说：

- 单晶/粉末 X 射线衍射可以得到电子密度图或结构模型；这不是“透镜成像”，而是“衍射 + 相位问题/模型精修”。
- X 射线成像技术（如透射 X 射线显微、相干衍射成像）确实存在，但常规 X 射线晶体学不是直接给原子照片。
- 因此文案用“不提供一张原子照片”“记录衍射图，再反推”，不用“X 射线不能成像”。

### 2.2 “反射 ≠ 镜面反射”

布拉格公式常借助“晶面反射”讲光程差，这是教学几何模型。真实过程是原子/电子云的相干散射；只有在特定方向，散射波同相叠加。文案明确提醒，避免观众把晶体当成一堆镜子。

### 2.3 “峰宽 → 尺寸”

谢乐公式给出的是“相干衍射尺寸”，与晶粒尺寸相关但不总是相等：

- 单峰给出沿该晶面法向的厚度，不是三维粒径；
- 需扣仪器展宽；
- 应变、缺陷、堆垛层错也会展宽；
- K 值依赖晶粒形状、峰宽定义（FWHM/积分宽度）和拟合方法。

文案用“别急着拿它算粒径”“往往”“不是一颗颗粒的直径”，不承诺“测出粒径”。

### 2.4 “轻元素/氢”

X 射线主要与电子云作用，氢只有一个电子，散射贡献弱；在含重原子的晶体中，氢的位置往往难以由实验室 X 射线确定。同步辐射、中子衍射、电子衍射等可以提供互补信息。文案用“往往更难”，不绝对化。

## 3. 画面文字核对

| 画面文字 | 核对 |
|---|---|
| `X 射线 λ ≈ 0.15 nm` | 1.5406 Å ≈ 0.154 nm；用“≈”正确 |
| `2d sinθ = nλ` | 正确；θ 标注为射线与晶面夹角 |
| `d：晶面间距` | 正确 |
| `强度 vs 衍射角 2θ` | 正确；2θ 是入射束与衍射束夹角 |
| `F(hkl) = Σ fᵢ e^{2πi(hxᵢ+kyᵢ+lzᵢ)}` | 结构因子标准形式；画面只作标签，不要求计算 |
| `β = Kλ / (L cosθ)` | 谢乐公式标准形式；K 不写具体值 |
| `仪器 + 尺寸 + 应变/缺陷` | 正确但简化；实际还有堆垛层错、孪晶、吸收等 |
| `长程有序 → 峰；无序 → 鼓包` | 正确；准晶等特殊情况不展开 |
| `束斑内是平均结果` | 正确；束斑大小因仪器而异 |
| `擅长：平均结构；很难：局部缺陷` | 正确；不是“不能”，是“很难单独回答” |
| `通常粉末压进槽里就能测` | 正确但需“通常”限定；空气敏感样品、特殊附件例外 |
