# S02 分镜脚本（v0.1 · 待审定）

> 系列：看见原子
> 第二期：电子显微镜，如何把原子“拍”出来？
> 版本：v0.1，配合文案审定；下表时间为按 `audio/timing.json` 回填的实际值，分镜细节中的秒数是估算。
> 画幅：1920×1080 / 30 fps；视觉基调沿用 S01：深墨蓝 `#0B1020`、暖白 `#F4F1EA`、青绿 `#6FD3C7`、琥珀 `#D8A657`、珊瑚 `#E07A5F`。
> 关键改动：**视觉锚点挂在句子 id 上**，不挂在固定 `run_time` 上；每个镜头在对应句子开口时才动作。

## 0. 全局约定

- 左右各留 8%，顶部留 10%，底部 12% 为字幕带；关键图形不压字幕。
- 所有示意图左下角标“示意”；模拟高分辨图标“模拟计算 · 非实测”；第三方照片标来源。
- 不出现终端、代码、路径、软件界面、工具水印、调试网格。
- 颜色语义：青绿 = 电子束/波；琥珀 = 测量/晶面/关键数字；珊瑚 = 边界/损伤/不可见；灰蓝 = 辅助线。
- 允许 0.5–1 秒静止；不要求每帧都有动画。
- 画面不追求“每段都对称居中”；仪器可以偏左，标尺可以偏右，给字幕留气口。

## 3. 声音设计

- 旁白：Qwen3-TTS 1.7B CustomVoice，`serena`，逐句 `instruct`；句间 0.35 s，场景间 0.65 s；按句做轻微 `atempo`，不整体变速。
- 配乐：原创 MIDI，68 BPM，A 小调，28 小节（约 99 s）循环；钢琴 + 暖 pad + 大提琴 + 稀疏钟琴；LMMS + SF2 Player（GeneralUser GS）。床轨约 −23 LUFS，旁白约 −18 LUFS，混后 −16 LUFS。
- 侧链：旁白出现时配乐下压 2–4 dB；公式/关键数字处留 0.5–0.8 s。
- 音效：极少量；只在“绿屏亮起”“离焦反转”“两张结果卡”三处；不用卡通音效。
- 静默：S00_07 问题后留 0.8 s；S02_15 “两件事”后留 0.6 s；S07_05 问题后留 1.0 s 进片尾。

## 4. 音画同步方案（针对 S01 的偏差）

S01 的问题不是“混音没对齐”，而是**场景内部没有时间锚点**：场景总长按音频算，但镜头动画用固定 `run_time`，剩余时间全部堆到场景末尾。

S02 改为：

1. TTS 逐句生成，`timing.json` 记录每句 `start/end`；
2. 每个视觉动作在 `sentences.json` 里绑定一个句子 id（`visual` 字段 + 分镜表）；
3. Manim 场景用 `TimelineScene.cue("S04_06")`：等到该句开始再播动画，动画 `run_time` 由下一句的开始时间反推；
4. 如果动画会超过下一个锚点，自动压缩到锚点前 0.15 s；
5. 渲染后用 `scripts/check_s02_sync.py` 对照 `timing.json` 与场景日志，报告每个 cue 的偏差；目标 |Δ| ≤ 0.15 s。

### 5.1 动效语言（v0.2，参考 3b1b）

- 镜头承担叙述：从 16 单位宽推到 5.8，再拉回 12；“推近=注意这里，拉远=看关系”。
- 一个镜头一个念头：相机运动、对象变换、文字写入不同时做；留 0.5–1 s 静止读图。
- 连续变换优先：能用一个 `Transform` 讲清楚的，不淡出再淡入；公式/标签用 `TransformMatchingTex` 的同一思路。
- 空间层次：等距 3D 晶格作背景、深度排序、低透明度；主体仍是样品/屏幕/图像。
- 原子柱：从俯视（一列叠成一个点）转到侧视（一列点），把“投影”直接演出来。
- 光：荧光屏用径向辉光；颗粒用 `LaggedStart` 逐颗亮；`Flash` 只用于聚焦/命中两个时刻。
- 不做：粒子飞散、镜头光晕、电子音效、每帧都在动的“呼吸感”。
- 实现与参考见 [`manim/README.md`](manim/README.md)；S00 样片为 [`renders/sync_demo.mp4`](renders/sync_demo.mp4)。
