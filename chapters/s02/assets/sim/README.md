# S02 模拟高分辨像（SrTiO₃ [001]）

> 这些图是**计算出来的**，不是实验照片。
> 用途：解释“亮点 = 原子列投影”“离焦会反转亮点/暗点”“厚度方向会叠加”。
> 生成脚本：`scripts/build_s02_sim_tem.py`；参数：`sim_srtio3_001.json`。

## 文件

| 文件 | 条件 | 用途 |
|---|---|---|
| `sim_srtio3_001_sr_under.png` | 5 nm，离焦 −20 nm，Sr 列亮 | S05 主图；S00_06 的“原子列” |
| `sim_srtio3_001_sr_over.png` | 5 nm，离焦 +20 nm，Sr 列暗 | S04_06 的“亮点变暗点” |
| `sim_srtio3_001_sr_thick.png` | 12 nm，离焦 −20 nm | S04_07 的“厚度投影” |
| `sim_srtio3_001_sr_under_blur.png` | 对主图做高斯模糊 | S00_05 的“图像一开始是糊的” |

## 模型与边界

- 200 kV，λ = 0.0250793 Å；Cs = 1 mm；弱相位物体 + CTF；非 multislice。
- 像素 0.08 Å，512×512，视场约 41 Å。
- **只画 Sr 原子列**，所以亮点构成 3.905 Å 的方格子；Ti/O 列被省略，不等于它们不存在。
- 有轻微厚度楔形、泊松噪声、暗角；用于“看起来像一张图”，不用于定量匹配。
- 画面必须标“模拟计算 · 非实测”；旁白明说“不是实拍”。
