## 2. 需要避免的说法

| 说法 | 问题 | 本稿处理 |
|---|---|---|
| “电子显微镜能看到所有原子” | 理论波长足够短，但像差、剂量、样品厚度限制实际分辨率 | 改为“波长够短，但实际卡在透镜” |
| “高分辨像就是原子照片” | 相位衬度 + 投影 + 模拟依赖；亮点不等于单个原子 | 整段 S04 纠正；S05 用模拟图说明 |
| “球差校正后一定能看到单个原子” | 还受样品、剂量、稳定性限制 | 只说“分辨率能到一埃上下；好一点的，半个埃” |
| “电子衍射比 X 射线更准” | 两者回答不同问题；电子衍射有动力学散射、强度难定量 | 全稿用“另一种看法”，不做高下判断 |
| “样品越薄越好” | 太薄信号弱、表面效应强；不同模式有不同最佳厚度 | 分别说 50–100 nm 与 <10 nm，不说“越薄越好” |
| “峰/点越亮就一定是重原子” | HRTEM 亮度受离焦、厚度、相位影响；HAADF 才更直接反映 Z | S04_12–S04_14 区分 HRTEM 与 HAADF |
| “X 射线完全不会损伤样品” | 蛋白质、有机物等也会辐照损伤 | 本稿未说“完全不损伤”；只对比“通常温和” |
| “电镜看到的就是整块材料” | 薄区取样偏差 | S06 明确“薄区未必代表整体” |

## 3. 待补充/待确认

1. **真实 HRTEM 实拍图**：当前 S05 使用自算模拟图，标注“模拟计算，非实测”。若操作员要求实拍，需要一张明确 CC0/PD 或书面授权的材料学 HRTEM 图，并核对材料、带轴、电压、离焦。
2. **SrTiO₃ 模拟参数**：当前为弱相位物体 + CTF 的教学级计算，不是 multislice；若要在片中标注“模拟”，建议同时给出参数（200 kV、Cs=1 mm、离焦 ±20 nm、厚度 5/12 nm），已写入 `sim_srtio3_001.json`。
3. **“球差校正后 0.5 Å”**：课程笔记写“现阶段透射电镜最大的分辨率是 0.5 Å”；不同设备/样品差异大，旁白用“好一点的”限定。若要给具体型号/年份，需要补充来源。
4. **“电子衍射 1–2 s”**：课程笔记为一般性描述；不同相机/样品差异大，旁白用“一两秒”而非精确值。
5. **X 射线与电子的“几十万倍”**：课程笔记为“接近数十万倍”；不同能量/元素有差异，旁白用“几十万倍”概括，不用于定量计算。
