# 《看见原子》系列主线设定

> 状态：阶段一 + 阶段二合并稿，等待操作员审阅。
> 更新日期：2026-10-31
> 适用范围：第一期（S01）及后续各期的统一创作规范。
> 配套文档：[反 AI 味工作法](writing_guide.md)、[三级信息架构](information_architecture.md)。

## 1. 目标受众

- 主要受众：理工科本科生、研究生，材料、化学、物理、纳米科技方向；对“材料结构表征”有好奇心，但没有系统学过晶体学。
- 次要受众：具备高中物理“波、干涉、衍射”基础的科普观众。
- 不假设观众知道：晶面指数、倒易空间、结构因子、卷积、傅里叶变换。
- 假设观众知道：原子、电子、波长、角度、曲线图的基本读法。

## 2. 系列核心问题

**我们看不见原子，凭什么知道它们怎样排列？**

系列不把答案落在某一种“万能仪器”上，而是逐步建立三个判断：

1. 要观察原子尺度，探测波的波长必须与原子间距相当。
2. X 射线衍射把三维周期结构编码成倒易空间中的峰；它擅长回答“平均结构是什么”。
3. 电子显微把电子波重新汇聚成像；它擅长回答“这个局部发生了什么”。两种“眼睛”看到的是不同层次的信息，不能互相替代。

## 3. 系列主线

### 第一层：尺度问题

可见光波长约 400–700 nm，原子间距约 0.1–0.3 nm。用可见光看原子，不是“放大倍数不够”，而是探测波长与目标尺度不匹配。

### 第二层：X 射线衍射

X 射线波长可到约 0.15 nm。晶体中周期性排列的原子面把入射波散射到特定方向；满足布拉格条件时相长干涉，形成衍射峰。粉末样品把三维取向平均成圆锥，探测器扫描得到强度—角度曲线。

一张衍射图主要读出三件事：

- **峰位**：晶面间距 → 晶胞形状和大小。
- **峰强**：原子种类、位置、占有率、温度因子等 → 晶胞内部结构。
- **峰宽**：晶粒尺寸、晶格应变、缺陷、仪器展宽 → 晶体的完整程度与尺度。

### 第三层：电子显微

电子波长更短（200 kV 约 0.025 Å），与物质作用更强。电子显微镜用磁透镜控制电子束，既能记录电子衍射，也能在实空间成像。它可以看到单个晶粒、界面、缺陷和原子列，但样品必须很薄，且可能被电子束损伤。

### 第四层：互补

| 维度 | X 射线衍射 | 电子显微 |
|---|---|---|
| 主要空间 | 倒易空间 | 实空间 + 倒易空间 |
| 结果 | 大范围平均结构 | 局域结构、形貌、缺陷 |
| 样品 | 粉末、块体、单晶 | 极薄切片或纳米颗粒 |
| 损伤 | 相对温和，但采集可能很慢 | 电子束强，容易辐照损伤 |
| 典型问题 | 平均晶胞、物相、晶粒尺寸 | 这个晶粒、这个界面、这个缺陷 |

系列要避免的简化：不说“X 射线看不见原子，电子显微镜才能看见原子”。更准确的说法是：**X 射线通过衍射“读出”平均结构，电子显微镜通过成像“看见”局域结构。**

## 4. 每期主题规划

| 期号 | 暂定标题 | 核心问题 | 状态 |
|---|---|---|---|
| S01 | 一束 X 射线，如何读出原子排列？ | 衍射图怎样编码晶胞、原子位置和晶体完整性？ | 已制作，待验收 |
| S02 | 电子显微镜，如何把原子“拍”出来？ | 电子波长、磁透镜、电子衍射和实空间成像怎样配合？ | 规划中 |
| S03 | 同一块材料，为什么两种“眼睛”看到的不一样？ | 平均与局域、倒易与实空间、无损与损伤如何互补？ | 规划中 |
| S04（可选） | 从一张图谱到一块材料 | 缺陷、相变、纳米析出物如何改变衍射与图像？ | 待定 |

第一期只承担“X 射线衍射能读出什么”这一件事，不抢讲电子显微的细节；结尾只做桥接，避免信息过载。

## 5. 单期规格

- 时长：8–10 分钟；S01 成片 9 分 38 秒（含片尾 1:10）。
- 画幅：1920×1080，30 fps，H.264/AAC。
- 结构：冷开场（问题）→ 建立尺度 → 核心原理 → 一张图的读法 → 边界 → 下一期钩子。
- 旁白字数：按 220–235 字/分钟控制；S01 约 1720 字。
- 镜头节奏：平均 6–12 秒一个视觉动作；公式镜头可停留 8–15 秒。
- 字幕：中文，单行不超过 22 字，最多两行；底部安全区内。

## 6. 视觉语言

### 色彩

- 背景：深墨蓝 `#0B1020`，不是纯黑，避免“科技黑”压抑感。
- 主文字：暖白 `#F4F1EA`，比纯白柔和。
- 光束/电子束：青绿 `#6FD3C7`。
- 测量/晶面/重点：琥珀 `#D8A657`。
- 警示/边界：珊瑚 `#E07A5F`，只用于“看不到/会失真”等提醒。
- 网格/辅助线：灰蓝 `#263044`，低对比，不抢主体。

### 图形

- 细线矢量图，不用写实 3D 渲染；避免“炫技”压过概念。
- 原子用圆点/半透明圆表示；晶面用半透明平面；波用细正弦线。
- 公式只在图形建立直觉之后出现；公式旁边必须有一句人话解释。
- 示意图统一标注“示意”，合成数据统一标注“模型数据，非实测”。
- 不使用终端、代码窗口、文件管理器、安装界面、工具水印、调试网格。

### 字体

- 标题/正文：思源黑体 CN（Source Han Sans CN）。
- 引用/章节数字：思源宋体 CN（Source Han Serif CN），少量使用。
- 手写感标注：霞鹜文楷（LXGW WenKai），只用于“批注”层，不用于大段正文。
- 字体文件全部放入 `assets/fonts/`，渲染时显式注册/指定，避免系统缺字。

## 6.1 封面规范

- 画幅：**16:9**，默认 1920×1080。
- 核心内容必须落在**居中的 4:3 安全区**：1920×1080 画布上为 1440×1080，横向 x=240–1680；标题、主体图示、必要说明不得越界。
- 背景、光效、辅助线可以延伸到全幅 16:9，但裁掉左右两侧后，封面仍然完整、可读。
- 核心内容距 4:3 边界至少留 3% 安全边距；不要把文字或关键图形压在边界上。
- 导出前必须做一次“中心 4:3 裁切”检查，并保留裁切预览供质检。
- 封面不出现路径、命令、环境名、工具水印、调试标记；必要的数据来源用极简文字标注。
- 封面字体、配色与正片一致：思源黑体/宋体、霞鹜文楷；深墨蓝、暖白、青绿、琥珀。

## 7. 旁白语气

- 冷静、清楚、有一点好奇；不煽情，不喊口号。
- 像一个人在实验室里解释，而不是主持人在台上报幕。
- 先给画面能验证的直觉，再给术语；术语第一次出现时用一句话解释。
- 多用具体动作、物件、数字；少用“极其重要”“深远影响”这类空话。
- 允许短句、停顿、没说完的话；把一部分解释交给画面。
- 允许有限度的拟人（“峰位最老实”“X 射线有脾气”），但不连续卖萌。
- 不用“首先/其次/最后”“第一/第二/第三”做清单式推进；用语义转折。
- 不用“让我们”“你一定想不到”“见证奇迹”这类主持人腔。
- 不使用“黑科技”“颠覆”“万能”“一眼看穿”等夸张词。
- 不把科学家写成孤胆英雄；需要时用“布拉格父子”“研究者”这类平实表述。
- 不编造个人经历；用可核实的现场细节替代。

## 8. 科学准确性原则

1. **区分测量与模型**：衍射图是测量，原子结构是反演/精修得到的模型；不要把模型说成“照片”。
2. **区分平均与局域**：X 射线束斑内的结果是平均；电子显微可以局域，但也有取样偏差。
3. **区分必要条件和充分条件**：满足布拉格条件是出现衍射峰的必要条件；峰强还受结构因子、占有率、温度因子、择优取向等影响。
4. **不把峰宽只归因于晶粒尺寸**：仪器展宽、晶格应变、缺陷都会贡献；谢乐公式给出的是“相干衍射尺寸”的估计，不是万能粒径。
5. **不把“反射”当镜面反射**：布拉格公式中的反射是几何模型；真实过程是原子/电子云的相干散射。
6. **不绝对化**：不说“X 射线显微镜不存在”“X 射线只能看谱不能成像”。更准确：常规 X 射线晶体学不直接给出原子级实空间图像，而是从衍射反演结构。
7. **数字要可追溯**：波长、角度、分辨率等数字必须来自课程笔记或可靠来源；示意图中的数字标注“示例”。
8. **不确定就问**：术语读法、历史细节、具体材料数据，若没有把握，列入待确认项，不编造。

## 9. 片尾与署名

- 片尾只保留简洁署名：科学内容支持、字体、动画/旁白、参考资料位置。
- 许可证全文、素材 URL、作者、下载日期放入 `docs/assets_and_licenses.md`。
- 不在画面中出现课程平台账号、学校内部路径、软件安装信息。
- 片尾建议文案见 `docs/credits.md`。

## 10. 反“AI 味”写作

具体方法、改写动作、自查清单和 S01 前后对照，见 [`docs/writing_guide.md`](writing_guide.md)。

三条硬规则：

1. 不写“首先/其次/最后”“第一/第二/第三”的清单腔；用具体转折推进。
2. 不写“不是……而是……”“不仅……而且……”的连续对称句；拆成短句。
3. 不写“所以这告诉我们……”的段尾总结；让画面和下一句自己接上。

## 11. 三级信息架构

观众、操作员、内部工作层的边界，见 [`docs/information_architecture.md`](information_architecture.md)。

一句话：**观众只看科学内容、可信表达和必要署名；命令、路径、环境、日志、许可证、Agent 工作流不进成片。**
