# 科普文案反“AI 味”工作法

> 用途：写出更像人在解释、而不是模型在完成任务的旁白与字幕。
> 适用：本系列所有期数；也适用于分镜说明、视频简介。
> 不是“骗过 AI 检测器”。目标是：具体、可听、有人味，同时不牺牲科学准确。
> 相关文档：[三级信息架构](information_architecture.md)、[系列主线](program_mainline.md)。

## 1. 先承认一件事

AI 没有在实验室里站过一下午，也没有闻过样品、被导师打断过、或者对着一台坏掉的仪器生过气。它没有这些“身体记忆”。

所以，反 AI 味不是让 AI 假装有这些经历。那会变成另一种假。

可用的办法是：

- 用**可核实的现场细节**代替虚构的个人故事；
- 用**具体的动作、物体、数字**代替空泛的形容词；
- 用**不均匀的节奏**代替每段都四平八稳；
- 允许**没说完的话**和**需要画面补全的空白**；
- 把“总结”删掉，让观众自己得出结论。

一句话：**AI 做枝叶，人做树干。** 这一期里，“树干”是课程笔记、实验常识和真实数据；不是编出来的“我当年在实验室……”。

## 2. “AI 味”通常长什么样

不是某个词的问题，是几个习惯叠在一起。

### 2.1 结构太整齐

- 每段都是“观点—解释—总结”；
- 每段长度差不多；
- 每隔几句就“首先/其次/最后”“第一/第二/第三”；
- 每个部分都要升华一下；
- 结尾一定要“这不仅……而且……”。

这种结构适合报告，不适合一个人对另一个人讲话。

### 2.2 英语式长句

- 长定语套长定语：“一个由……所构成的、能够……的、在……中发挥作用的系统”；
- 名词化：“进行测量”“实现提升”“做出判断”，而不是“测”“提高”“判断”；
- 对称句：“不是……而是……”“不仅……而且……”“既……又……”连续出现；
- 抽象主语：“这种现象说明了……”“这一过程体现了……”。

### 2.3 空泛的“大词”

“极其重要”“深远影响”“至关重要的角色”“不可或缺”“为……提供了有力支撑”。

这些词不是不能说，而是说了等于没说。换成具体后果：

- 不好：“晶胞参数非常重要。”
- 较好：“晶胞多大，决定了原子能站多近，也影响它们怎么成键。”

### 2.4 过度解释

每出现一个概念，立刻解释；每解释完，立刻总结；每总结完，立刻升华。

观众没有喘息，画面也没有工作可做。结果就是“听君一席话，如听一席话”。

### 2.5 假亲密

“让我们一起来看看”“你一定想不到”“接下来，见证奇迹的时刻”。

这种主持人腔，和实验室里两个人对着样品说话，是两套语言。

### 2.6 比喻堆叠

一个比喻还没落地，下一个比喻又来了。比喻本身不坏，但不能延伸，一延伸就错。

叶李华的说法很直接：举例有百利而无一害，比喻却不一定；比喻不能随便延伸，否则一定会失效。

## 3. 七个改写动作

### 动作 1：从具体物件/动作开场

不要从定义开场。从一个样品、一个动作、一个数字、一个异常现象开场。

- 差：“X 射线衍射是一种重要的材料表征方法。”
- 好：“一小堆白色粉末，装在样品槽里，表面被刮得很平。看上去像面粉。”

后者不是文学修饰，它给画面一个落点，也给观众一个“然后呢”。

### 动作 2：一句只做一件事

长句拆短。该停顿的地方停顿。

- 差：“当 X 射线照射到具有周期性原子排列的晶体上时，会在满足布拉格条件的方向上产生相长干涉。”
- 好：“X 射线照到晶体上。原子向各个方向发出次波。方向对了，它们叠成一条亮线。”

短句不是幼稚。短句是让观众有时间把画面和话对上。

### 动作 3：把名词变成动作

- “进行测量” → “测”
- “实现提升” → “提高”
- “做出判断” → “判断”
- “对结构进行分析” → “看结构”

动词让句子站起来。

### 动作 4：删掉一半路标词

“首先、其次、最后、值得注意的是、不难发现、由此可见、综上所述”。

删完以后，如果句子还接得上，说明本来就不需要。

### 动作 5：打破对称

- 不要每段都用“观点 + 例子 + 结论”；
- 不要每段都三句话；
- 不要每个转折都用“然而”；
- 不要每个排比都三项。

允许一段只有一句话。允许一个段落突然变长。允许一句话不解释完。

### 动作 6：把一部分工作交给画面

旁白不必把画面已经说清楚的东西再说一遍。

- 画面：峰位标记落到 2θ 轴，公式出现。
- 旁白：“峰位最老实。每一个峰位对应一个晶面间距。”

不用再说“我们可以看到，峰位在横坐标上对应一个角度，这个角度可以通过布拉格公式换算成晶面间距”。画面已经在做这件事。

### 动作 7：朗读，再试听

写完后读一遍，录音听一遍。标记三种地方：

1. 一口气读不完的句子 → 拆；
2. 听起来像在念论文的句子 → 改口语；
3. 连续三句以同一个词开头 → 换。

TTS 试听还能抓到书面语里看不出的问题：停顿不对、重音不对、符号读错。

## 4. 自查工具

旁白定稿后先跑：

```bash
make copy-check
```

它只做提示：清单腔、对称句、空泛转折、过长句、重复句首、L0 禁用词。命中不等于写错，但值得再看一眼。

## 5. 自查清单

### 结构

- [ ] 开场是具体物件/动作/问题，不是定义。
- [ ] 没有连续使用“首先/其次/最后”。
- [ ] 没有每段都总结。
- [ ] 段落长度不均匀。
- [ ] 至少有一处“没说完”，交给画面。

### 句子

- [ ] 长句不超过 45 字；超过就拆。
- [ ] 没有连续三个“不是……而是……”。
- [ ] 没有连续三个“不仅……而且……”。
- [ ] 没有长定语套长定语。
- [ ] 动词没有被名词化。
- [ ] 每段至少有一个具体名词/数字/动作。

### 语气

- [ ] 没有“让我们”“你一定想不到”“见证奇迹”。
- [ ] 没有“极其重要”“深远影响”这类空话。
- [ ] 拟人只用一两处，不连续卖萌。
- [ ] 有科学限定词，但不每句都“可能/或许”。
- [ ] 读起来像一个人在解释，不像在念报告。

### 准确性

- [ ] 每个数字有来源。
- [ ] 比喻没有延伸出错误结论。
- [ ] 没有为了“人味”编造个人经历。
- [ ] 没有为了顺口牺牲限定条件。

## 7. 什么时候“AI 味”不是问题

技术文档、操作手册、会议纪要、报告：清楚、可检索、少歧义比“人味”重要。

但科普旁白、视频简介、面向观众的标题，属于高熵文本。那里需要判断、取舍、语气和一点毛边。

## 8. 不要做的三件事

1. **不要编造个人经历。** “我在实验室遇到……”如果没有，就不写。用可核实的操作细节替代。
2. **不要为了“人味”牺牲准确。** “峰越宽，晶粒一定越小”很顺口，但错。保留“通常”“往往”“还要看仪器展宽”。
3. **不要把 AI 检测器当目标。** 检测器会变；观众不会。目标是让人听懂、愿意听下去。

## 9. 参考与延伸

- 叶李华《科普创作经验谈：技巧、原则与怀疑精神》，中国作家网，2020-04-03。  
  https://www.chinawriter.com.cn/n1/2020/0403/c404080-31660301.html  
  可用点：多讲故事、举生活化例子、比喻不能延伸、图解要简单、重复/螺旋推进、主动为读者释疑。
- 《「AI 味」的本质是什么？你可能搞错了！》，网易号，2026-01-05。  
  https://m.163.com/dy/article/KIGAVOME0511805E.html  
  可用点：AI 味常来自英语式句法、过度平滑的结构；仅靠禁用词不够。
- 《去不掉的 AI 味儿》，阿里云开发者社区，2026-09-19。  
  https://developer.aliyun.com/article/1764611  
  可用点：AI 倾向“总—分—总”、均匀、安全、缺少毛边；人机协作应是“人做树干，AI 做枝叶”。
- ACS, *Writing About Science for Nonscientists*。  
  https://inchemistry.acs.org/careers/writing-for-nonscientists.html  
  可用点：面向非科学家的写作，需要减少术语、解释背景、使用具体例子。
